## 컴퓨터의 기본 구성

### 하드웨어의 구성

1. 컴퓨터 필수 장치
    
    초기 폰노이만 구조 컴퓨터는 CPU와 메인 메모리만으로 구성되어있다.
    
2. 컴퓨터 주변 장치
    - 입력장치: 키보드, 마우스 등
    - 출력장치: 모니터, 프린트, 스피커 등
    - 저장장치: 하드디스크, SSD 등
3. 메인보드와 버스
    
    다른 장치들을 연결하고 전원을 공급하는 회로 기판인 메인보드가 있고, 메인보드에 장치 간 데이터 통로가 있는데 이를 버스라 부른다. 정해진 경로를 따라 데이터를 각 장치에 전달한다.
    

### 폰노이만 구조

현대의 모든 컴퓨터는 폰노이만 구조를 기반으로 설계된다.

폰노이만 구조는 CPU, 메모리, 주변장치가 버스로 연결된 형태이다.

가장 중요한 특징은 모든 프로그램은 메모리에 올라와야만 실행이 가능한 구조이다.

### 기초 용어 정리

- 클록
    
    컴퓨터에서 모든 작업을 일정한 박자인 클록에 맞춰서 진행된다.
    
    10번의 행동을 해야한다면 10번의 클록 신호가 지나야 작업이 완료된다.
    
- 헤르츠
    
    컴퓨터의 성능을 나타내는 단위로 Hz로 표기한다.
    
    1초 동안 발생한 클록 신호의 횟수를 의미한다.
    

## CPU와 메모리

### CPU의 구성과 동작 방식

CPU는 명령어를 해석하고 실행하는 핵심 장치이다.

- 산술논리 연산장치: 약어로 ALU는 데이터의 산술 연산과 논리 연산을 수행한다.
- 제어장치: 명령어를 해석하고 다른 장치에 작업을 지시한다.
- 레지스터: 연산에 필요한 데이터나 중간 결과를 임시로 저장하는 메모리

### 레지스터 자세히 알기

### 레지스터의 종류

- 데이터 레지스터(DR): 메모리에서 가져온 데이터를 보관하거나 작업의 결과를 임시 저장
- 주소 레지스터(AR): 처리할 데이터가 저장된 메모리 주소를 저장
- 프로그램 카운터(PC): 다음에 실행할 명령어의 위치를 저장
- 명령어 레지스터(IR): 현재 실행 중인 명령어를 저장
- 메모리 주소 레지스터(MAR): 메모리에서 CPU로 데이터를 가져오거나 반대일 경우 메모리 주소를 저장하는 레지스터
- 메모리 버퍼 레지스터(MBR): 메모리에서 CPU로 가져온 데이터나 반대일 경우 데이터를 임시로 저장
- 프로그램 상태 레지스터(PSR): 연산 결과의 상태를 나타내며 플래그 레지스터라고도 부른다.

### 레지스터 동작 과정

<img width="1094" height="521" alt="image" src="https://github.com/user-attachments/assets/75652876-7eb0-4328-8c63-738f99289953" />

1. 프로그램 카운터에 실행해야 하는 코드의 주소가 저장되어 있다. 제어장치에 주소가 전송되면 1행을 읽고 명령어 레지스터에 저장된다.
2. 제어장치가 명령어 레지스터에 있는 명령을 읽고 데이터를 가져오는 제어 신호를 보낸다.
3. 메모리 주소 레지스터에 메모리 주소가 저장되고 해당 주소에 있는 값을 메모리 버퍼 레지스터로 보낸다.
4. 제어장치가 메모리 버퍼 레지스터에 저장된 값을 가지고 연산을 한다.

### 버스의 구조

시스템 버스는 CPU와 메모리, 주변장치 간에 데이터를 주고받는 통로이다.

1. 제어 버스: 제어버스는 CPU의 제어장치, 메모리, 주변장치와 연결되어 신호를 양방향으로 전달한다.
2. 주소 버스: 주소버스는 CPU와 메모리, CPU와 주변장치를 연결하여 작업할 주소를 단방향으로 전달한다
3. 데이터 버스: 데이터버스는 CPU와 메모리 또는 주변장치에 연결되어 실제 데이터를 양방향으로 전달한다.

### 메모리의 종류

메인 메모리는 데이터를 1바이트 단위로 저장하며 각각의 바이트는 주소로 구분된다.

메모리는 크게 램와 롬으로 구분된다.

- 램: 데이터를 읽고 쓸 수 있는 메모리
- 롬: 데이터를 쓸 수 없고 저장된 데이터만 읽을 수 있다.

일반적으로 메모리라고 말하면 램을 의미한다.

램은 휘발성과 비휘발성으로 나뉜다.

- 휘발성: 전원이 없을 때 데이터가 사라지는 반도체 메모리
- 비휘발성: 전원이 없는 동안에도 데이터를 보관할 수 있다.

메인 메모리에는 동작이 빠른 휘발성 메모리를 사용하고 저장장치는 비휘발성 메모리를 사용한다.
