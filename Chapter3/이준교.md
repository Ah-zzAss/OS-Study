### 30. PCB에 대하여 설명하시오.

운영체제는 프로세스가 실행되는 동안 필요한 다양한 정보를 PCB에 저장한다.

시분할 시스템을 기반으로 여러 개의 프로세스를 동시에 실행하는 멀티태스킹에서는 프로세스가 CPU를 사용하다가 다른 프로세스에 CPU를 넘겨준 후, 다시 CPU를 할당받아 작업을 이어가는데, 이때 이전의 작업 상태를 저장하고 다시 불러올 수 있도록 PCB에 관련 정보를 기록한다.

### 31. 프로세스의 구조를 설명하시오.

프로세스는 운영체제와 관련된 `커널 프로세스`와 일반적인 프로세스인 `사용자 프로세스`로 나뉜다.

메모리에서 프로세스의 실행 코드는 `코드 영역`과 `데이터 영역`으로 나뉜다.

- 코드 영역

    - 프로그램의 본문에 해당하는 영역으로, 텍스트 영역이라고도 부른다. 
    - 읽기 전용이다.

- 데이터 영역

    - 편집 중인 문서 데이터가 저장되는 영역이다.
    - 읽기와 쓰기가 가능하다.
    - 정적 데이터 영역, 힙 영역, 스택 영역으로 나뉜다.

### 32. 프로세스의 5가지 상태를 설명하시오.

- 생성 상태

    - 프로그램이 메모리에 올라와 프로세스가 생성된 상태이다.
    - 생성 상태의 모든 프로세스는 즉시 실행되지 않고 준비 큐에 삽입되어 준비 상태가 된다.

- 준비 상태

    - 운영체제가 프로세스에 CPU가 할당되기를 기다리는 상태이다.

- 실행 상태

    - CPU를 할당받아 실제 작업을 수행하는 상태이다.
    - 주어진 시간을 다 사용하고도 작업이 끝나지 않았다면 프로세스는 준비 상태로 돌아가 다음 차례를 기다린다.
    - 시간 안에 끝났다면 완료 상태로 이동한다.

- 대기 상태

    - 실행 중인 프로세스가 입출력을 요청한 후에 기다리는 상태이다.
    - 입출력이 완료되면 대기 상태로 갔던 프로세스는 준비 상태로 옮겨진다.

- 완료 상태

    - 프로세스가 모든 작업을 완료한 상태이다.

### 33. 문맥 교환에 대하여 설명하시오.

CPU를 사용하던 프로세스를 중단하고 새로운 프로세스로 전환하는 과정이다.

실행 상태에서 나가는 프로세스의 PCB에는 지금까지의 작업 내용을 저장하고, 프로세스가 실행 상태로 들어오면 레지스터의 값을 PCB에 저장된 값으로 변경한다.
